Curso de desarrollo Frontend

El objetivo de este modulo es que las alumnas adquieran un dominio fundamental en el desarrollo Front End, enfocándose en la maquetación web con HTML y CSS. Al finalizar, serán capaces de crear páginas web estáticas, bien estructuradas y visualmente atractivas, utilizando correctamente etiquetas HTML para organizar contenido y aplicando estilos con CSS para personalizar su diseño y apariencia. Las alumnas aprenderán a trabajar con layouts, tipografías, colores, y elementos visuales, desarrollando habilidades prácticas que les permitirán construir interfaces responsivas y atractivas, preparándolas para continuar con tecnologías más avanzadas en el mundo del desarrollo web.

  1. Introduccion a HTML
  2. Introduccion a CSS
  3. Introduccion a Sass
  4. Introduccion a JavaScript
  5. Introduccion a React
